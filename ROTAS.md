# Lista de rotas

Prefixo: "localhost:8080" (Exemplo)

* GET "/" -> Página principal

# Rotas de clientes

* GET "/clientes/" -> Todos os clientes.
* POST "/clientes/" -> Criação de um cliente
* PATCH "/clientes/:id" -> Atualização de informações de um cliente
* DELETE "/clientes/:id" -> Excluir um cliente
