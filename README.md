# DevLink
Versão: v2.7.0

## Tecnologias utilizadas
- Bun.js (Runtime)
- Typescript
- Elysia (Similar ao express)
- Better Auth (Autenticação)
- Drizzle-orm
- Next.js (Framework Front-End)
- Postgresql (Banco de dados)

## Pré-requisitos
- Bun.js (1.4.0+)
- PostgreSQL(Versão 17+)

## Instalação

1. Clonar o repositório:
```
git clone https://github.com/jvitor-hash/Projeto-sem-nome
cd '.\Projeto sem nome\'
```

2. Instalação das dependências do projeto:
```
bun install
```

3. Configuração das variáveis de ambiente: (BACK-END)
```
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=
FRONT_END_URL=
DATABASE_URL=
LOGGER_LEVEL="ERROR"
PORT=3333
```

3.1 Configuração das variáveis de ambiente: (FRONT-END)
```
API_URL=
```
